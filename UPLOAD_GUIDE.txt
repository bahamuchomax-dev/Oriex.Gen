GitHub Pages アップロード手順

1. このZIPを解凍する
2. 中にあるファイルをすべてGitHubリポジトリへアップロードする
   - index.html
   - 404.html
   - .nojekyll
   - .gitignore
   - UPLOAD_GUIDE.txt
3. GitHub の Settings → Pages を開く
4. Source を「Deploy from a branch」にする
5. Branch を「main」、Folder を「/root」にする
6. Save を押す

注意
- .env は入れていません。
- assets フォルダは不要です。
- ZIPファイル自体ではなく、解凍した中身をアップロードしてください。
- FirebaseのWeb公開設定はビルド済みJSに含まれます。FirestoreのSecurity Rulesは必ず確認してください。
